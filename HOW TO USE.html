StudyFlow – How to use

A simple guide for people who aren't programmers.

What is this? How to open it Adding a task Classes & work hours The AI helper Every day Closing it Problems?

1What did I download?

StudyFlow is a weekly planner. You tell it what you need to do (for example, "study for the statistics exam, 2 hours, by Thursday"), and it finds free time in your week and puts it on your schedule for you.

The app is in Hebrew. In this guide, Hebrew words in green boxes are the exact words you'll see on screen, so you can match them.

It's saved in this folder on your computer: C:\Users\noanz\Study\StudyFlow-Handmade

The folder has a lot of files. You only need two of them:

  • Open StudyFlow Handmade: double-click it to start the app.
  • HOW TO USE: this guide.

You can ignore all the other files. They're the app's "engine".

🔒 Your information stays private. Everything you type is saved only in your browser on this computer. Nothing is sent to the internet (except what you say to the AI helper, if you use it), and nothing changes on GitHub (the website you downloaded it from).

2How to open StudyFlow

  1. Open the folder C:\Users\noanz\Study\StudyFlow-Handmade (open File Explorer → This PC → C: → Users → noanz → Study → StudyFlow-Handmade).
  2. Double-click the file Open StudyFlow Handmade.
  3. A black window appears. Leave it open. It's what makes the app run.
  4. After about 2 seconds, your browser opens StudyFlow automatically.
⚠️ Don't double-click index.html. It only shows a white page. Always use Open StudyFlow Handmade.

If Windows shows a blue box saying "Windows protected your PC", click More info → Run anyway. This happens with any file you create yourself.

Quicker next time

Right-click Open StudyFlow Handmade → Show more options → Send to → Desktop (create shortcut). You'll then have an icon on your desktop.

While the black window is open, you can also type this address in Chrome: http://127.0.0.1:4174

3What's on the screen

+ הוספת משימה or the round + buttonAdd something new (a task or a class)
היוםToday: your plan for today, hour by hour
השבועThis week: all 7 days at a glance
משימותTasks: a list of everything you added
העדפותSettings: which hours you're available, breaks, days off

Easiest way to learn: click איך משתמשים? (how to use) at the bottom of the side menu (on a phone, it's the ? at the top). A short tour circles each button and explains it. Click English on the note to read it in English.

Want to see how it looks with tasks first? On the empty start screen, click לראות דוגמה (see an example). To go back to your own empty planner, click חזרה לתוכנית שלי at the top.

4Adding a task (something you need to do)

Click + הוספת משימה. A window opens. Make sure the tab משימה שצריך לעשות (a task to do) is selected. Then fill in:

מה תרצה לקדם?, "What do you want to work on?"Type the name of the task.
Example: Study for statistics exam, Write history essay, Do laundry. You can type in English or Hebrew.
כמה זמן בערך?, "About how long will it take?"Click one of the buttons: חצי שעה = 30 minutes, שעה = 1 hour, שעתיים = 2 hours. You can also type any number of minutes in the small box.
Big tasks are split into smaller study blocks automatically.
עד מתי?, "By when?"Choose the deadline date. The task will be scheduled before then.
העדפה אישית ועוד אפשרויות, "More options" (optional, you can skip it) מתי נוח לך? = when you prefer to do it (morning / afternoon / evening), סוג המשימה = type (study / personal / work), חשיבות = importance.

Click להוסיף ולמצוא זמן (add and find time). Done! The task now appears in your plan.

5Adding classes, work shifts or training (fixed times)

Use this for things that happen at a set time. StudyFlow won't put tasks during those hours.

Click + הוספת משימה, then click the tab פעילות בשעה קבועה (activity at a fixed time).

מה קורה?, "What is it?"
Example: Math lecture, Work at the café, Gym
תאריך התחלה, "Start date"The day it happens (or the first time it happens).
משעה / עד שעה, "From" / "Until"Start time and end time.
זה חד־פעמי או חוזר בכל שבוע?, "One time, or every week?" פעם אחת בלבד = only once.
בכל שבוע, למספר שבועות = every week, for a number of weeks.
בכל שבוע, למשך שנה = every week, for a year.
בכל שבוע, עד תאריך שאבחר = every week, until a date you choose.
If it repeats, pick the days of the week (א׳ = Sunday, ב׳ = Monday … ש׳ = Saturday).

Click להוסיף לתוכנית (add to plan).

🎙The AI helper: just say it

Instead of filling in the form, click העוזר החכם (the smart helper) in the side menu (on a phone, the 🎙 at the top). Press the big microphone and talk, for example:

מחר בחמש ללמוד למבחן בסטטיסטיקה שעתיים, וביום שלישי יש לי שיעור מעשר עד שתים עשרה כל שבוע

  1. Press the microphone again when you're done. Your words appear as text, and you can fix them or type instead.
  2. Click להבין מה אמרתי (understand what I said).
  3. The helper shows a card for everything it understood. Nothing is added yet. Fix a name, or untick anything you don't want.
  4. Click להוסיף לתוכנית (add to plan).

The first time, Chrome asks to use your microphone. Click Allow.

Connecting it (one time only)

The helper uses Claude, an AI made by Anthropic. It needs an API key, a kind of password that lets StudyFlow use Claude. Each request costs about 1 cent, paid to Anthropic from credit you add.

  1. Go to console.anthropic.com and create an account.
  2. Open Billing and add a small amount of credit (the minimum is fine).
  3. Open API Keys → Create Key, give it a name like "StudyFlow", and copy it. It starts with sk-ant-.
  4. Open Notepad, paste the key, and choose File → Save As. Go to the folder C:\Users\noanz\Study\StudyFlow-Handmade, set Save as type to All files, name it ai-key.txt, and click Save.
  5. Close the black window and double-click Open StudyFlow Handmade again.
🔑 Keep the key secret. Anyone with it can spend your credit. Don't send it to anyone or post it online. If it ever leaks, delete it in the Anthropic console and make a new one.

🔒 Privacy: when you use the helper, your recording is turned into text by Google (through Chrome), and that text is sent to Anthropic to be understood. The rest of StudyFlow still stays only on your computer.

6Using it every day

Open היום (Today) to see what to do and when. On each card:

✓ סיימתי"I finished": click when you've done that block
לדחות בשעהPostpone by one hour
עריכהEdit
🗑 (trash can)Delete
Round circle next to a task (in משימות)Click it to mark the whole task as done

Click any day number at the top to see that day's plan.

Made a mistake? After every change a black message pops up at the bottom. Click ביטול (undo) in it.

If you see an orange box saying tasks didn't fit (לא נכנסו לזמן הפנוי), your week is too full. Open it and either change the deadline or allow more hours in העדפות.

7Closing StudyFlow

Close the browser tab, then close the black window. That's it. Your tasks are saved and will still be there next time you open it.

Your tasks are saved in this browser only. If you open StudyFlow in a different browser (for example Edge instead of Chrome), it will look empty. Always use the same browser.

To keep a backup: העדפות → גיבוי והעברה למכשיר אחר → הורדת גיבוי (download backup).

?Problems

I see a white, empty page.

You probably opened index.html directly. Close it and double-click Open StudyFlow Handmade instead.

The browser says "This site can't be reached".

The black window is closed. Double-click Open StudyFlow Handmade again.

The black window says "address already in use".

StudyFlow is already running. Just use the browser tab, or go to http://127.0.0.1:4174.

The helper says it isn't connected, or the key is wrong.

Check that the file is called exactly ai-key.txt (not ai-key.txt.txt), that it's in the StudyFlow-Handmade folder, and that it contains only the key. Then restart the black window.

The microphone doesn't work.

Use Chrome, and allow the microphone: click the lock icon next to the address, then turn on Microphone. You can always type instead.

The black window says Node.js is needed.

Go to nodejs.org, download the LTS version, install it with the default options, then try again.
